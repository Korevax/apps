# Korevax Apps

Repositório que contém as aplicações do ecossistema **Korevax**.

> Korevax is an open-source ecosystem for discovering, organizing, connecting and exploring digital content.

## Estrutura
apps/

└── web/             # *Aplicação web principal (React + TypeScript + Vite + Ionic)*

## Aplicação Web (`web`)

Frontend oficial do Korevax.

### Tecnologias

- **React** + **TypeScript**
- **Vite**
- **Ionic React**
- **Ionicons**
- CSS (com variáveis centralizadas)

### Características

- Interface responsiva (desktop, tablet e mobile)
- Suporte a internacionalização (i18n)
- Arquitetura baseada em componentes reutilizáveis
- Design minimalista (preto, branco e roxo)

### Navegação principal prevista

- Descobrir
- Popular
- Recentes
- Coleções

### Como rodar localmente

```bash
cd web
npm install
npm run dev
```

### Sobre o Korevax
O Korevax é um ecossistema open-source focado em:

Catálogo estruturado de conteúdos digitais (filmes, séries, animes, livros, jogos, etc.)
Knowledge Graph (entidades + relações semânticas)
Metadados verificáveis e com histórico
Contribuição comunitária
APIs para interoperabilidade
